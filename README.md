# Simulating Deglacial Radiocarbon Anomalies with pH-Neutral Geologic Carbon

This repository contains code and model output used in the study _Simulating Deglacial Radiocarbon Anomalies with pH-Neutral Geologic Carbon_, submitted to *Paleoceanography and Paleoclimatology*.

## Contents

- `scripts/`: Python scripts for running the regional model and generating figures
- `src/`: Core model code used for the the regional model
- `scripts/GoCmodel.py`: Main driver script for the Gulf of California model
